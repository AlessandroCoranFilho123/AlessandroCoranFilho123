A lightweight text editor for Windows, made with WinUI 3. It was born from the desire to have something as large and simple as the classic Notepad, with native support for.txt and tabs, instead of one window per file.
A Windows desktop productivity application focused on note management.

Exploring native Windows development, user interface design, application architecture, and performance optimization.
